# اكتشاف مجموعات البيانات من الكتالوج العالمي للاكتشاف الخاص بـ WIS2

!!! abstract "نتائج التعلم!"

    بنهاية هذه الجلسة العملية، ستكون قادرًا على:

    - استخدام pywmocat لاكتشاف مجموعات البيانات من الكتالوج العالمي للاكتشاف (GDC)

## المقدمة

في هذه الجلسة، ستتعلم كيفية اكتشاف البيانات من الكتالوج العالمي للاكتشاف الخاص بـ WIS2 (GDC) باستخدام [pywmocat](https://github.com/wmo-im/pywmocat)، وهو أداة سطر أوامر للبحث واسترجاع البيانات الوصفية من GDC الخاص بـ WIS2.

حاليًا، الكتالوجات العالمية للاكتشاف (GDCs) المتاحة هي:

- خدمة الأرصاد الجوية الكندية، البيئة وتغير المناخ في كندا: <https://wis2-gdc.weather.gc.ca/collections/wis2-discovery-metadata>
- الإدارة الصينية للأرصاد الجوية: <https://gdc.wis.cma.cn/collections/wis2-discovery-metadata>
- خدمة الأرصاد الجوية الألمانية: <https://wis2.dwd.de/gdc/collections/wis2-discovery-metadata>

خلال جلسات التدريب المحلية، يتم إعداد كتالوج عالمي محلي للاكتشاف (GDC) للسماح للمشاركين بالاستعلام عن الكتالوج للحصول على البيانات الوصفية التي قاموا بنشرها من مثيلات wis2box الخاصة بهم. في هذه الحالة، سيقوم المدربون بتوفير عنوان URL الخاص بـ GDC المحلي.

## التحضير

!!! note
    قبل البدء، يرجى تسجيل الدخول إلى الجهاز الافتراضي الخاص بك كطالب.

## تثبيت pywmocat

استخدم مثبت حزم Python `pip3` لتثبيت pywmocat على جهازك الافتراضي:
```bash
pip3 install pywmocat
```

!!! note

    إذا واجهت الخطأ التالي:

    ```
    WARNING: The script pywmocat is installed in '/home/username/.local/bin' which is not on PATH.
    Consider adding this directory to PATH or, if you prefer to suppress this warning, use --no-warn-script-location.
    ```

    قم بتشغيل الأمر التالي:

    ```bash
    export PATH=$PATH:/home/$USER/.local/bin
    ```

    ...حيث `$USER` هو اسم المستخدم الخاص بك على الجهاز الافتراضي.

تحقق من أن التثبيت تم بنجاح:

```bash
pywmocat --version
```

## العثور على البيانات باستخدام pywmocat

بشكل افتراضي، يتصل pywmocat بالكتالوج العالمي للاكتشاف (GDC) المستضاف من قبل البيئة وتغير المناخ في كندا (ECCC).

!!! note "تغيير عنوان URL الخاص بـ GDC"
    إذا كنت تقوم بهذا التمرين خلال جلسة تدريب محلية، يمكنك تكوين pywmocat للاستعلام عن GDC المحلي عن طريق تعيين متغير البيئة `PYWISCAT_GDC_URL`:

    ```bash
    export PYWMOCAT_WIS2_GDC_URL=http://gdc.training.wis2dev.io/collections/wis2-discovery-metadata
    ```

لرؤية الخيارات المتاحة، قم بتشغيل:

```bash
pywmocat wis2-gdc search --help
```

يمكنك البحث في GDC عن جميع السجلات:

```bash
pywmocat wis2-gdc search
```

!!! question

    كم عدد السجلات التي يتم إرجاعها من البحث؟

??? success "اضغط للكشف عن الإجابة"
    يعتمد عدد السجلات على GDC الذي تقوم بالاستعلام منه. عند استخدام GDC التدريب المحلي، يجب أن ترى أن عدد السجلات يساوي عدد مجموعات البيانات التي تم إدخالها في GDC خلال الجلسات العملية الأخرى.

دعنا نحاول الاستعلام عن GDC باستخدام كلمة مفتاحية:

```bash
pywmocat wis2-gdc search -q observations
```

!!! question

    ما هي سياسة البيانات للنتائج؟

??? success "اضغط للكشف عن الإجابة"
    يجب أن تحدد جميع البيانات التي يتم إرجاعها بأنها بيانات "أساسية".

جرب استعلامات إضافية باستخدام `-q`

!!! tip

    يتيح لك العلم `-q` الصياغة التالية:

    - `-q synop`: العثور على جميع السجلات التي تحتوي على الكلمة "synop"
    - `-q temp`: العثور على جميع السجلات التي تحتوي على الكلمة "temp"
    - `-q "observations AND oman"`: العثور على جميع السجلات التي تحتوي على الكلمات "observations" و"oman"
    - `-q "observations NOT oman"`: العثور على جميع السجلات التي تحتوي على الكلمة "observations" ولكن ليس الكلمة "oman"
    - `-q "synop OR temp"`: العثور على جميع السجلات التي تحتوي على "synop" أو "temp"
    - `-q "obs*"`: بحث تقريبي

    عند البحث عن مصطلحات تحتوي على مسافات، قم بوضعها بين علامات اقتباس مزدوجة.

دعنا نحصل على مزيد من التفاصيل حول نتيجة بحث معينة تهمنا:

```bash
pywmocat wis2-gdc get <id>
```

!!! tip

    استخدم قيمة `id` من البحث السابق.
